# The input system (area INT)

The design, the protocol and the normative requirements of the input system are DOC-1781 and DOC-1782 of `neoteletext-common/PROTOCOL.html` (protocol version 2, decision E.100), shared with NeoTeletext. This file held the design of version 1, the 14-byte key record of decision E.90, which version 2 replaced on 21 October 2026; its text is in this repository's history.
